## 🎯 What Is Ultra Prompt?

**Ultra Prompt** is a Claude Code skill that acts as your **senior principal engineer + product visionary + UX genius + creative director** — all combined into one prompt architect.

You type a single sentence. Ultra Prompt outputs a **complete, zero-ambiguity build specification** that any senior developer could use to ship a world-class product.

<br/>

```
YOU TYPE:        "bikin app fitness"

ULTRA OUTPUTS:   → Full product name & brand identity
                 → Complete tech stack with justification  
                 → 40+ feature specs with acceptance criteria
                 → Database schema (12 tables, RLS policies, indexes)
                 → Full design system (colors, typography, motion)
                 → Security architecture (auth, encryption, compliance)
                 → Performance benchmarks (< 1.5s cold start, 60fps)
                 → Monetization strategy ($9.99/mo freemium)
                 → 8-week delivery roadmap
                 → CI/CD pipeline specification
                 → Onboarding flow (magic moment in < 60 seconds)
                 → Analytics event catalogue
                 → Accessibility (WCAG 2.2 AA complete)
                 → And 20+ more sections of pure precision
```

## 🏗️ What Ultra Prompt Covers

Every generated prompt includes **all 20 sections** — no skeleton, no placeholders, all populated with real, specific, actionable content:

<br/>

<details>
<summary><b>📋 Executive Summary & Vision</b></summary>
<br/>

- Product name, brand identity, and unique voice
- One-liner, vision, mission, UVP
- Hyper-specific user personas (not "25-40 year olds" — real people with real problems)
- Success metrics with actual numbers (D1/D7/D30 retention targets, MRR goals)

</details>

<details>
<summary><b>🏗️ Technical Architecture</b></summary>
<br/>

- Full tech stack with every layer justified (why Supabase over Firebase, why Riverpod over Bloc)
- Complete folder structure to copy verbatim
- Third-party integrations with specific SDK versions
- Infrastructure & DevOps setup (CI/CD, monitoring, secrets management)

</details>

<details>
<summary><b>🎨 Design System & Visual Identity</b></summary>
<br/>

- Complete color palette (hex values + semantic meaning + WCAG contrast ratios)
- Typography scale (font choices, sizes, line heights, weights)
- Spacing system (4px base grid, complete scale)
- Animation principles (duration, easing curves, micro-interactions)
- Icon system specification

</details>

<details>
<summary><b>📱 Complete Feature Specification</b></summary>
<br/>

- Every feature with: user story, acceptance criteria, UI/UX flow spec, edge cases, technical implementation notes
- Prioritized: Core MVP → Secondary → Future Roadmap
- No feature is left as "add a way for users to do X" — every one is fully designed

</details>

<details>
<summary><b>🗄️ Data Model</b></summary>
<br/>

- Complete SQL schema with all tables, fields, types, constraints
- Row Level Security (RLS) policies for every table
- Indexes for performance-critical queries
- Entity relationship diagram in text format

</details>

<details>
<summary><b>🔐 Security Architecture</b></summary>
<br/>

- Authentication strategy (OAuth providers, JWT config, biometric)
- Encryption at rest and in transit
- OWASP Top 10 mitigation for every vulnerability
- Rate limiting, input validation, CORS configuration
- GDPR/privacy compliance specification

</details>

<details>
<summary><b>♿ Accessibility (WCAG 2.2 AA)</b></summary>
<br/>

- Screen reader support (VoiceOver/TalkBack) — every component
- Keyboard navigation complete specification
- Color contrast requirements with actual ratios
- Touch target sizes, text scaling, motion preferences

</details>

<details>
<summary><b>⚡ Performance Requirements</b></summary>
<br/>

- Specific, measurable benchmarks (not "fast" — "< 1.5s cold start")
- Mobile: startup time, frame rate, memory, battery
- Web: LCP, INP, CLS, TTFB targets with percentile specs
- Scalability: concurrent user targets, horizontal scaling triggers

</details>

<details>
<summary><b>🧪 Quality Assurance Strategy</b></summary>
<br/>

- Test coverage requirements per layer (unit/widget/integration/E2E)
- Critical path test scenarios written out
- CI/CD pipeline spec (every step from PR to production)
- Performance testing in the pipeline

</details>

<details>
<summary><b>💰 Monetization Architecture</b></summary>
<br/>

- Pricing tiers with specific amounts and what's included
- Paywall placement strategy (after the "magic moment" — never on open)
- Revenue psychology tactics (trial, urgency, social proof, loss aversion)
- Winback campaign specification

</details>

<details>
<summary><b>🎯 Onboarding Flow Design</b></summary>
<br/>

- Screen-by-screen specification (what's shown, why, what CTA)
- The "magic moment" strategy: user gets value BEFORE creating an account
- Personalization questions and how answers affect the product
- Permission request timing and pre-permission modals

</details>

<details>
<summary><b>🔔 Notification Strategy</b></summary>
<br/>

- Push notification types, triggers, and exact copy templates
- Smart scheduling (user's active hours, quiet periods)
- In-app notification specifications (toast, banner, modal)
- Email sequence (welcome series, re-engagement, transactional)

</details>

<details>
<summary><b>📊 Analytics & Observability</b></summary>
<br/>

- Complete event catalogue (acquisition → activation → engagement → retention → monetization)
- Dashboard specifications for real-time, daily, weekly views
- Error monitoring setup (Sentry, PagerDuty integration)
- A/B testing infrastructure

</details>

<details>
<summary><b>🌍 Internationalization & Localization</b></summary>
<br/>

- Language support strategy
- ARB/i18n file structure
- Date, time, currency, number formatting
- RTL support specification

</details>

<details>
<summary><b>🗓️ Phased Delivery Roadmap</b></summary>
<br/>

- Week-by-week delivery plan (Foundation → MVP → Monetization → Growth)
- Every task in each phase listed specifically
- Dependencies and blockers called out
- Milestone definitions

</details>

<details>
<summary><b>🛠️ Developer Experience</b></summary>
<br/>

- Code standards (linting, formatting, PR size limits)
- Commit conventions, branch naming, documentation requirements
- Local development setup (< 5 minutes goal)
- Architecture Decision Records (ADRs) process

</details>

<details>
<summary><b>🎁 Magic Moments Checklist</b></summary>
<br/>

- Every moment that turns users into advocates — specified
- First open, first success, first milestone, upgrade, return after churn
- Each must be intentionally designed, not an afterthought

</details>

<details>
<summary><b>❌ Anti-Patterns Specification</b></summary>
<br/>

- Explicit list of forbidden patterns (UI, code, product)
- No spinners on load, no generic errors, no dark patterns
- Code: no hardcoded secrets, no force-unwrap, no god classes
- Product: feature before polish, launch without monitoring

</details>

<details>
<summary><b>🚀 ASO & App Store Strategy</b></summary>
<br/>

- Title, subtitle, keywords optimized for discovery
- Screenshot content specifications (all 6-10 frames)
- Preview video script (30-second "magic moment" showcase)
- Review response strategy

</details>

<details>
<summary><b>✅ Definition of Done</b></summary>
<br/>

- 15-point checklist every feature must pass before "done"
- Code review, tests, accessibility, analytics, performance — all required
- Non-negotiable gates prevent shipping incomplete work

</details>

## 🚀 Installation

### Method 1 — Clone directly into Claude Code skills

```bash
# Clone into your Claude Code skills directory
git clone https://github.com/verycoolapps/Ultra-Prompt.git ~/.claude/skills/ultra-prompt

# That's it. Restart Claude Code (or reload skills).
```

### Method 2 — Manual install

```bash
# 1. Download SKILL.md
curl -o ~/.claude/skills/ultra-prompt/SKILL.md \
  https://raw.githubusercontent.com/verycoolapps/Ultra-Prompt/main/SKILL.md

# 2. Reload Claude Code skills
```

### Method 3 — Using Claude Code skill installer

```
/install-skill verycoolapps/Ultra-Prompt
```

<br/>

**Verify installation:**
```
/skills
```
You should see `ultra-prompt` in the list. ✅

## 📖 How It Works

### Basic Usage

```
/ultra-prompt [your idea]
```

**Examples:**
```bash
/ultra-prompt bikin app fitness iOS

/ultra-prompt social media for pet owners

/ultra-prompt SaaS platform for managing freelance projects

/ultra-prompt casual mobile game with satisfying mechanics

/ultra-prompt AI writing assistant web app
```

### Enhance an Existing Prompt

Simply paste your rough prompt and add "enhance this:":

```
enhance this: build a todo app with React that has good UX
```

Ultra Prompt will transform it from a basic request into a complete product specification.

### Domain Auto-Detection

Ultra Prompt automatically detects your project type and adapts:

| Your Words | Ultra Detects | Stack Generated |
|---|---|---|
| "app iOS", "flutter", "mobile" | iOS/Android Mobile | Flutter + Supabase |
| "web app", "website", "SaaS" | Web Application | Next.js + Supabase |
| "game", "casual", "puzzle" | Mobile/Web Game | Unity / Phaser |
| "macOS", "desktop", "mac app" | Desktop Application | Swift + SwiftUI |
| "API", "backend", "service" | Backend System | FastAPI / Node.js |
| "AI", "chatbot", "LLM" | AI Application | Python + Claude API |
| "extension", "browser plugin" | Browser Extension | Manifest V3 |
| "CLI", "terminal", "script" | CLI Tool | Rust / Go |

## 💡 Pro Tips

<br/>

**🎯 Tip 1 — Less is more at input**
```
✅ "bikin app meditation"        → Ultra fills the vision
❌ "bikin app meditation yang ada guided sessions, ambient sounds..."
```
Let Ultra be bold. You can always redirect.

<br/>

**🎯 Tip 2 — Redirect Ultra's assumptions**
When Ultra states assumptions, you can redirect any of them:
```
Ultra assumed: Flutter (iOS-first)
Your redirect: "actually use React Native + Expo"
→ Ultra regenerates with your preferred stack
```

<br/>

**🎯 Tip 3 — Use the output as your actual PRD**
The Ultra Prompt output is comprehensive enough to:
- Hand directly to a development team
- Use as a PRD for investor pitches
- Copy-paste into your project's SPEC.md
- Feed back into Claude Code for step-by-step implementation

<br/>

**🎯 Tip 4 — Stack it with other skills**
```
/ultra-prompt fintech app
→ Get the spec

Then use the spec with:
/plan → implementation plan
/ultra-prompt output → ask Claude Code to implement feature by feature
```
